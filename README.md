# 使用指南

本帮助文档旨在指导用户如何使用 Gateway Switch 工具和 Clash Verge 进行智能代理切换配置。

## 使用方法

### 使用 Clash Verge 加载配置

1. 打开 Clash Verge，点击左侧菜单中的“订阅”。
2. 点击右上角的“新增”按钮。
3. 在弹出的“新建配置”窗口中：
   - 如果选择 `Local` 类型，点击“选择文件”，选择当前项目下的 `gateway-switch\gateway.yaml` 文件。
4. 点击“保存”完成配置。
5. 开启规则模式&tun模式（虚拟网卡）

完成后，Clash Verge 将自动加载并应用该配置。

### 使用本地工具

双击 `start-proxy.bat`，保持窗口打开即可。

脚本会自动完成以下操作：

1. **关闭系统手动代理**（注册表 `ProxyEnable` → 0）
2. **设置 PAC 自动配置**（注册表 `AutoConfigURL` → `http://127.0.0.1:9999/proxy.pac`）
3. **启动本地 HTTP 服务** 监听 `127.0.0.1:9999`，提供 PAC 文件

#### 自定义 PAC 文件

- **修改代理地址**：编辑 `proxy.pac` 中的 `192.168.103.145:8080` 和 `192.168.103.145:8888`
- **添加分流规则**：编辑 `proxy.pac` 中对应分组的域名列表
- **修改端口**：编辑 `start-proxy.ps1` 第2行 `$port = 9999`

按 `Ctrl+C` 停止后，脚本会自动清除 PAC 配置，恢复系统默认设置。

## 路由规则

| 流量类型      | 目标                   | 说明      |
| ------------- | ---------------------- | --------- |
| 广告域名      | `0.0.0.0:0`            | 屏蔽广告  |
| 局域网 / 本地 | DIRECT                 | 直连      |
| 国内域名      | `192.168.103.145:8080` | CN 网关   |
| 国际域名      | `192.168.103.145:8888` | INTL 网关 |

路由规则可通过编辑 `proxy.pac` 文件进行自定义，具体方法请参考“使用本地工具”部分的自定义说明。
